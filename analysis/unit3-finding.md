# Unit 3 Finding: Airline Booking

To the Dashboard Team: The dashboard reported that about half of bookings ended in a passenger no-show, prompting a hold on the route profitability review and associated quarterly payout. The supplied data contains 200 bookings made during 2023, of which 12 are recorded passenger no-shows: **6% of all bookings**. There are 156 confirmed bookings, 34 cancelled bookings, and 10 disputed bookings. Passenger no-shows account for 12 of the 34 cancellations; the remaining 22 cancellations have other causes. A disputed booking is a separate outcome and should not automatically be counted as a passenger no-show.

The audit reproduced a filtering error that quiletly leaves out 166 bookings with no cancellation reason. Comparing only the bookings with a recorded reason changes the no-show rate from 6% to 35.29%. This demonstrates how excluding ordinary bookings can inflate the rate, but it does not reproduce the reported figure of about half. The original dashboard query was not supplied, so the exact calculation remains unknown. A second example tried to filter on a calculated label before that label was available, the database rejected it, and both corrected versions now return the same results. This second error would stop a query, rather than silently change its results.

Replace the dashboard calculation with the corrected full-population measure and withdraw the no-show finding used to fix the hold. Reopen the route profitability review and recommend releasing the quarterly payout if this incorrect finding was the only reason it was frozen.... any separate eligibility or profitability checks still need to be completed. The provided file does not establish a payout amount or a quarterly breakdown of the hold. Before the dashboard is used again, make sure that all 200 bookings are included, keep cancellations and disputes distinct, compare the reported figures with the underlying records.
